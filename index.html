Reachy Mini App

Morning Briefing

Umbrella, next bus and the news. Say good morning and Reachy Mini gets you out the door in Stavanger.

Getting Started

Installation

Install this app on your Reachy Mini using the app store, or run it locally:

uv sync
reachy-mini-daemon --sim  # in another terminal
python -m morning_briefing.main --ui --no-camera

What it says

Three sources, one briefing

Rain check from MET Norway, live departures from Entur for your home stop, and the top NRK headlines. Speech runs on the Hugging Face realtime backend, so no API key is needed. Stop, coordinates and feed are set with environment variables; see the README.
